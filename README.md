# CHIP-8 Emulator

A low-level emulation project built to explore the fundamentals of system architecture and hardware simulation. 

## Project Objective
The goal of this project is to learn basics at least of **Low-Level Development (LLD)**. Chip-8 seemed the perfect start point.

## Got to Learn
* **Bitwise Manipulation:** Direct handling of opcodes and memory masking.
* **The Fetch-Decode-Execute Cycle:** Implementing the core heartbeat of a CPU.
* **Memory Mapping:** Managing a 4KB virtual address space, registers, and stack.
* **Ebiton:** Handling display and key input thru Ebiton

---

## Architecture Overview
The CHIP-8 is the perfect intro emulator better accessible than the Game Boy, but just difficult enough to teach the basics.


## Tech Stack
* **Language:** Go
* **Graphics/Input:** Ebiton
